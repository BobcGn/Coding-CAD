# 范围 / Scope

`implementation-validator` 比较批准的 Architecture IR、可选 Execution Blueprint 与 Implementation Analyzer 模型，输出可解释的 Compliance Report。

`implementation-validator` compares approved Architecture IR, an optional Execution Blueprint, and an Implementation Analyzer model to emit an explainable Compliance Report.

不在范围内：仓库扫描、源码/AST 解析、技术检测、代码修改、PR、Agent 调用和 IDE 插件。

Out of scope: repository scanning, source/AST parsing, technology detection, code mutation, PRs, Agent invocation, and IDE plugins.
