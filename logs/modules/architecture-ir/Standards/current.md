# 当前实施标准 / Current Implementation Standards

更新时间 / Updated at: 2026-08-08 18:41 CST (Asia/Shanghai)

- IR 类型必须稳定、可扩展、AI 友好。
- 逻辑角色与技术绑定必须分离。
- 不在 IR package 中加入解析器、验证器或 UI 假设。

- IR types must be stable, extensible, and AI friendly.
- Logical roles and technology bindings must remain separated.
- Do not add parser, validator, or UI assumptions to the IR package.
