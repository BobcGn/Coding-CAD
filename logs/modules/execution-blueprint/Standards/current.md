# 当前实施标准 / Current Implementation Standards

更新时间 / Updated at: 2026-08-09 00:35 CST (Asia/Shanghai)

- Architecture IR 是唯一输入事实中心。
- Blueprint 不生成代码、不修改文件。
- Blueprint 不绑定具体 Coding Agent。
- 所有任务必须能追溯到 Architecture IR。
- 所有约束必须来自 Architecture Constraint、Architecture Decision、Validator Result 或 Component Limitation。

- Architecture IR is the single source of input truth.
- Blueprint does not generate code or mutate files.
- Blueprint does not bind to a concrete Coding Agent.
- Every task must trace back to Architecture IR.
- Every constraint must come from Architecture Constraints, Architecture Decisions, Validator Results, or Component Limitations.
