# 范围 / Scope

`implementation-analyzer` 将已有 Source Repository 的文件、manifest、模块和 import 证据映射为标准 `ArchitectureProject`。

`implementation-analyzer` maps file, manifest, module, and import evidence from an existing source repository into standard `ArchitectureProject`.

第一阶段优先支持 Node.js/TypeScript；不实现代码审查、完整 AST 理解、AI 解释、自动修复或代码修改。

Phase one prioritizes Node.js/TypeScript and excludes code review, full AST understanding, AI explanation, automatic remediation, and code mutation.
