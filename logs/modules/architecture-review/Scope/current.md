# 范围 / Scope

`architecture-review` 管理候选 Architecture IR 的 Proposal 生命周期、人工评论、批准决定和影响分析，并为已有 Execution Blueprint 流程提供批准门禁。

It manages proposal lifecycle, human comments, approval decisions, and impact analysis for candidate Architecture IR, providing an approval gate for the existing Execution Blueprint pipeline.

不在范围内：修改 IR、UI、Blueprint 生成、Agent 执行、代码生成和部署。

Out of scope: IR mutation, UI, Blueprint generation, Agent execution, code generation, and deployment.
