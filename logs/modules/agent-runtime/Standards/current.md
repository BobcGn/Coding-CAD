# 当前实施标准 / Current Implementation Standards

更新时间 / Updated at: 2026-08-08 18:41 CST (Asia/Shanghai)

- 先定义 Agent contract，再接入具体模型或外部 Coding Agent。
- Agent 输出必须可审计、可追踪、可由人类接管。
- 不让 Agent Runtime 反向污染 Architecture IR。

- Define Agent contracts before integrating specific models or external Coding Agents.
- Agent outputs must be auditable, traceable, and interruptible by humans.
- Do not let Agent Runtime leak assumptions back into Architecture IR.
